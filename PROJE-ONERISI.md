# Proje Önerisi

**1. Seçilen görev numarası:** Seçenek 1 - RAG Tabanlı Uzman Bilgi Asistanı

**2. Ürünün adı:** KodRehberi: C++ ve Java Dokümantasyon Asistanı

**3. Çözülecek problem:** Programlamaya yeni başlayan öğrencilerin C++ ve Java dillerindeki kalıtım, polimorfizm ve arayüzler (interfaces) gibi karmaşık nesne yönelimli programlama kavramlarını anlarken zorlanmaları ve internetteki dağınık bilgiler arasında vakit kaybetmeleri.

**4. Hedef kullanıcı:** Üniversitelerin ilgili bölümlerinde okuyan öğrenciler ve bu dilleri kendi kendine öğrenmeye çalışan yazılımcı adayları.

**5. Kullanılacak veri veya bilgi kaynakları:** C++ ve Java üzerine yazılmış güvenilir ders notları, açık kaynaklı dokümantasyonlar (örn. Oracle Java Docs, cppreference özetleri) ve nesne yönelimli programlama rehberlerinden oluşan en az 5 farklı PDF belgesi.

**6. Kullanılması planlanan teknolojiler:** * Programlama Dili: Python
* RAG Altyapısı: LangChain veya LlamaIndex
* Vektör Veritabanı: ChromaDB veya FAISS
* Arayüz: Streamlit

**7. Beklenen ürün çıktısı:** Kullanıcının C++ veya Java hakkında bir soru sorduğunda, yüklenen PDF dokümanlarını tarayarak doğru cevabı üreten, cevabın altına hangi dokümandan alındığını (kaynak) belirten ve web tarayıcısı üzerinden çalışan bir arayüz uygulaması.

**8. Ürünün diğer çalışmalardan ayrılan yönü:** Genel amaçlı yapay zeka modelleri gibi her konuda yüzeysel bilgi vermek veya uydurmak (halüsinasyon) yerine, sadece sisteme yüklenen spesifik programlama notlarına sadık kalarak kaynak garantili ve akademik öğrenmeye uygun cevaplar sunması.
